# Student Result Calculator

A simple Python program that takes student marks, calculates the average, and assigns a grade.

### Features

* Python, SQL and Aptitude marks
* Average and grade calculation
* Multiple students
* Input validation for marks
* Handles invalid input

### Grade

* 90+ → A
* 75–89 → B
* 60–74 → C
* Below 60 → D

### Concepts Used

Functions, loops, lists, dictionaries, conditions, and exception handling.
